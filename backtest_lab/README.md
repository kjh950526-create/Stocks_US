# backtest_lab — 포인트-인-타임 복기 실험실

Jeonghun 아이디어(2026-09-03): 미래를 모르는 상태로, 그날 아침까지의 데이터+뉴스+실적캘린더만 보고
사람처럼 판단해서 가상 트레이드 → 결과확인 → 배우고 규칙수정. 여러 전략/레짐/종목군으로 멀티버스.

## 핵심 원칙
- LOOK-AHEAD 절대금지: t일 아침 판단 = t-1 종가까지 + 그때까지 뉴스/기공지된 실적일정만.
- 체결: 장중 못보므로 시가/종가 기준. SL은 종가판정.
- ★단순 기계적 백테스트가 아니라: 가격+글로벌/이코노믹 뉴스+종목 실적/뉴스를 날짜대조해 "사람처럼" 판단.
- ★종목선택 로직 포함: 팩터강도 비교 + 개별펀더 + ADR기준 진입/스탑. 그냥 그룹평균 아님.

## 진행 로그
### 라운드 0 (2026-09-03): 기계적 시도 = 실패한 접근
- 순수 가격+SPY200MA 레짐만으로 진입방식(신고가/조정/벤치) 비교.
- 결과: 다 +0.2~0.8%로 비슷. 청산(20일선)이 진입차이를 묻어버림. 레짐차이도 안보임.
- ★결함1: 종목선택 없음 — 그룹 전체를 기계적 평균(팩터강도/펀더 비교 안함).
- ★결함2: 뉴스/실적/매크로 대조 없음 — Jeonghun 아이디어의 핵심 절반 누락.
- 교훈: 방법론(기계적BT)에 갇혀 진짜 목표(사람처럼 뉴스+가격 종합판단) 놓침. 재설계.

### 라운드 1 (재설계): 사람처럼 판단하는 케이스 복기
- 특정 과거시점 선택 → 그날까지 가격+뉴스+실적일정 재구성 → 판단 → 결과확인 → 학습.

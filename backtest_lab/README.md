# backtest_lab — 포인트-인-타임 복기 실험실

Jeonghun 아이디어(2026-09-03): 미래를 모르는 상태로, 그날 아침까지의 데이터+뉴스+실적캘린더만 보고
사람처럼 판단해서 가상 트레이드 → 결과확인 → 배우고 규칙수정. 여러 전략/레짐/종목군으로 멀티버스.

## 핵심 원칙
- LOOK-AHEAD 절대금지: t일 아침 판단 = t-1 종가까지 + 그때까지 뉴스/기공지된 실적일정만.
- 체결: 장중 못보므로 시가/종가 기준. SL은 종가판정.
- ★단순 기계적 백테스트가 아니라: 가격+글로벌/이코노믹 뉴스+종목 실적/뉴스를 날짜대조해 "사람처럼" 판단.
- ★종목선택 로직 포함: 팩터강도 비교 + 개별펀더 + ADR기준 진입/스탑. 그냥 그룹평균 아님.

## 진행 로그
### 라운드 0 (2026-09-03): 기계적 시도 = 실패한 접근
- 순수 가격+SPY200MA 레짐만으로 진입방식(신고가/조정/벤치) 비교.
- 결과: 다 +0.2~0.8%로 비슷. 청산(20일선)이 진입차이를 묻어버림. 레짐차이도 안보임.
- ★결함1: 종목선택 없음 — 그룹 전체를 기계적 평균(팩터강도/펀더 비교 안함).
- ★결함2: 뉴스/실적/매크로 대조 없음 — Jeonghun 아이디어의 핵심 절반 누락.
- 교훈: 방법론(기계적BT)에 갇혀 진짜 목표(사람처럼 뉴스+가격 종합판단) 놓침. 재설계.

### 라운드 1 (재설계): 사람처럼 판단하는 케이스 복기
- 특정 과거시점 선택 → 그날까지 가격+뉴스+실적일정 재구성 → 판단 → 결과확인 → 학습.

### 라운드 1 (2026-09-03): 케이스 복기 — 2022-01-27 약세장 진입직전
**방식: 그날까지 정보만 웹서치로 재구성 → 사람처럼 판단 → 미래확인.**
- 그날 알수있던것: CPI 7%(82년래최고), 3월 금리인상예상, 나스닥 11/19고점서 -9.7%+200일선 첫이탈
  (2020/4후 처음), VIX 52주최고, 유가 다년최고, 파월 매파.
- 우리 프레임 판단: 🔴방어(현금). 200일선이탈+매크로최악+성장주주도하락 = 신규진입금지.
- **미래확인: 판단 옳았음.** QQQ 이후 -24%, 성장주 샀으면 NVDA-49%/SHOP-69%/U-77%/SNOW-54%/NET-53%.
- **★핵심발견: 레짐필터(200일선+매크로)가 진짜 약세장 시작을 잡아냄.** 부록50의 "존버 근거=레짐, 레짐판단
  되냐가 최종병목" → 이 케이스는 "된다"는 증거(명확한 매크로전환은).
- 기계적BT(라운드0)는 뉴스를 못봐 "왜 방어하는지" 몰랐음. 사람처럼 판단하니 레짐필터 작동이 보임.
- 다음: 강세장 진입(2023초 회복)에서 "공격판단 맞았나" 검증해 균형.

### 라운드 2 (2026-09-03): 케이스 복기 — 2023-01-31 회복 국면 (애매한 케이스)
**그날 알수있던것: 2022 최악(-33% 나스닥), 컨센서스 압도적 침체예상("가장 예고된 침체"), 연준 여전 인상중,
1월 반등 시작했으나 전문가60% "약세장 반등, 안간다"(모건스탠리/뉴컨스트럭츠).**
- 우리 레짐필터: QQQ 200선+1%(회복)+50선+5%+기울기+0.9% = 🟢공격.
- **우리필터(공격) vs 전문가(약세반등) 정반대.**
- **미래확인: 우리가 맞음.** QQQ +39%(11개월), 성장주 NVDA+153%/CRWD+141%/META+138%/PLTR+121%,
  NVDA·CRWD·META 중간낙폭 0%(SVB사태도 안흔들림).

### ★★두 케이스 종합 발견: "가격(200선) > 뉴스/컨센서스"
| 시점 | 가격 | 뉴스/컨센서스 | 우리필터 | 결과 |
|---|---|---|---|---|
| 2022-01 | 200선이탈 | 매파(방어) | 방어 | ✅-24%회피 |
| 2023-01 | 200선회복 | 침체공포(방어) | 공격 | ✅+39%획득 |
- **핵심: 레짐판단은 가격(200선+50선기울기)이 뉴스/전문가컨센서스보다 정확.** 2023은 뉴스나쁜데 가격좋았고,
  가격따라 공격한게 맞았음. 매크로컨센서스는 오히려 역신호에 가까웠음.
- **왜: 200일선은 이미 모든 참여자의 뉴스해석이 반영된 결과.** "시장이 뉴스를 어떻게 소화했나"가 가격에 담김.
- **이게 "숫자가 뉴스를 못잡는다"(부록47)를 레짐차원에서 뒤집음:** 개별종목·단기는 뉴스가 뒤집지만(SNOW+25%),
  레짐(대세)은 가격이 뉴스보다 정확. 뉴스는 "왜"이해하는 보조, 판단 방아쇠는 가격(200선).

**★규칙: 레짐 = 200일선+50선기울기 신뢰, 매크로 컨센서스/공포는 무시or역이용.**
- 침체공포 팽배해도 200선회복+기울기상승이면 공격. 낙관팽배해도 200선이탈이면 방어.
